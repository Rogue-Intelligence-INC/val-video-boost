# 竞品分析与价值提升报告：Valhalla 无插件一致性栈

日期：2026-11-15 · 对象：`val-video-boost`（Rogue Intelligence 专有）· 配套：`docs/SUMMARY_REPORT.md`
市场信息经 2026-11-15 公开检索核对（官方文档/定价页为主，第三方比价仅作参考并标注）。

## 0. 一句话结论

**人物一致性正在被大平台标配化（参考图机制人人都有），单点功能没有壁垒；
我们的价值不在“又一个一致性功能”，而在平台不做的那一层：模型无关的、
可审计的、以弃权代替抽卡损耗的一致性控制层——而它恰好踩中 AI 短剧产业
当前最大的成本痛点（重抽损耗与爆款率）。** 窗口期存在但不长（估 12–24 个月），
提升路线应全部押在“把已验证机制变成可被制作管线调用的控制层 + 补齐
同台对标数据”，而不是去和平台拼生成模型。

## 1. 竞品地图（按与我们的距离分四圈）

### 1.1 第一圈：云端视频生成平台（直接竞品，都在用“参考图条件”解一致性）

| 竞品 | 一致性机制 | 关键事实（官方/公开来源） |
|---|---|---|
| Runway Gen-4/4.5 | References：1–3 张参考图，`@角色` 标签复用 | 2025-03 发布即主打“单图跨场景一致”；付费 $12–76/月，Gen-4.5 约 $2.83/5s（Standard 折算） |
| Google Flow / Veo 3.1 | Ingredients：最多 3 个“配料”（角色/物体/风格）；新版 Omni 加自拍 Avatar | 与 Gemini/YouTube 生态绑定；自有脸+声音多角度采集，自带 SynthID 水印 |
| Kling（快手） | Elements：1–4 张图选主体，可多主体互动 | 全球分发强；Standard 约 $6.6–8.8/月，5s/1080p 约 $1.0 |
| Vidu（生数） | Reference2Video：最多 7 主体 × 每主体 3 图，主体库 `server_id` 持久化，`[@name]` 调用，带音色 | 目前“多主体+多机位一致性”口碑最强一档；Q3 Turbo API 约 $0.04–0.06/s 起 |
| Hailuo（MiniMax） | S2V-01 Subject Reference：单张脸图 | 自称在动态视频中“超越微调模型”；已知短板是提示遵循下降 |
| PixVerse | Reference-to-Video：最多 7 图，`@ref_name` 绑定 | 经阿里云 Model Studio 提供 API，1–15s |
| Luma / Pika 等聚合器 | 转售 Kling/Runway 等多模型 + 自有编辑层 | 证明“多模型聚合+工作流层”本身就是一门生意 |

共同点：**一致性 = 把参考脸像素灌进生成**（即我们实测过的插件路线，
ArcFace 0.58–0.62 档）。它们的护城河是模型、算力、分发与品牌，
不是一致性机制本身。共同缺口（我们的机会）：

- 身份只能靠图携带，**没有结构化人物/故事层**：无冲突检查、无有效期
  （第 40 集换发型只从第 40 集起效）、无否定事实管理，参考图要人肉维护；
- **生成即交付，无验证/弃权**：漂了只能用户肉眼发现后重抽，
  “抽卡损耗”是用户自担成本，无分数、无审计记录；
- **锁死自家模型**：换模型 = 换工作流，角色资产不可迁移；
- 隐私与本地化：素材必须上云。

### 1.2 第二圈：图片侧角色一致性（同一问题，图片版已高度商品化）

| 竞品 | 机制 | 备注 |
|---|---|---|
| Midjourney V8.x Edit Model | 最多 4 张参考图 | 审美与用户基数无敌，视频仍是附属 |
| Ideogram Character / 4.5 | 单图建角色、Library 保存命名，1–5 参考 | “一张照片建角、按名复用”已被做成免费功能 |
| Leonardo | Omni 最多 6 参考；可训练 Character Elements（LoRA，10–50 图） | 参考路线与训练路线并存 |
| Higgsfield Soul ID 等 | 多图训练一个身份模型后无限复用 | 训练路线的代表 |
| Nano Banana / GPT Image 系 | 参考图编辑 | 大厂把“角色+场景编辑”做进通用图像模型 |

启示：图片侧“保存角色、按名复用”已是免费标配——**我们圣经里
“人物资产结构化保存”这件事本身不值钱，值钱的是它带的规则**
（逐字钉死、冲突、有效期、问法覆盖、验证分数）。

### 1.3 第三圈：开源/研究（可白嫖的替代实现，决定我们不能收“机制费”）

| 项目 | 内容 |
|---|---|
| ConsisID（CVPR 2025） | 基于 CogVideoX-5B 的免调优身份保持 T2V，频率分解注入；已进 diffusers |
| Phantom（Apache-2.0） | Wan 1.3B/14B 单/多主体参考生视频 |
| Stand-In | 只训 1% 参数的身份插件，可挂 VACE 等 |
| IP-Adapter / InstantID / PuLID / PhotoMaker | 图片侧身份注入全家桶（我们实测的 IP 路线即此） |
| OpenS2V-Nexus / OpenS2V-Eval | 主体生视频的公开评测基准（我们应直接采用，见 §4） |

启示：凡是“把脸注入模型”的机制，开源实现都在免费化。我们已用实验
证明且主动退役的补丁通道，本来也不可能成为壁垒。**能收钱的是
注入之外的东西：判断、选择、审计、跨模型编排。**

### 1.4 第四圈：相邻品类（抢同一笔预算，不抢同一功能）

- 数字人/口播：HeyGen（Avatar V，主打 30 分钟以上身份稳定）、
  Synthesia、Hedra——企业级年费约 $12k–60k，卖的是“同一个代言人
  讲一千条脚本”，叙事表演弱。证明**“锁定身份的复用权”在企业市场
  有明确付费意愿**，但形态是口播而非短剧叙事。
- 短剧制作平台：万兴剧厂（2026-03 上线，收入月复合 >100%）、
  各厂“AI 剧厂”——卖全链路产能。它们是我们的**潜在客户/渠道**，
  不是对手：它们缺的正是降低重抽损耗的质检层。
- 市场坐标（DataEye 等，2026 估）：中国 AI 剧/漫剧 >400 亿元
  （+138%），海外 AI 剧 >40 亿美元；行业共识是成本继续沿
  “模型降价、**减少抽卡损耗**、压缩流程”三条路下探，爆款率仅约
  0.47%、产能过剩转向拼质量。**“可度量的一致性质检”正好卡在
  第二条成本曲线上。**

## 2. 我们现在的价值（诚实分级）

### 2.1 已实测成立的资产（有数字、有复现脚本）

| 资产 | 证据 | 对竞品的差异 |
|---|---|---|
| 无插件一致性栈（供给+选择+验证） | Juggernaut 同台：0.657，最低 0.603，6/6 过 τ；IP 插件同台 0.581 | 平台的一致性必须用它的模型+参考图；我们**零参考图灌入、模型可换、本地可跑** |
| Fate 小接口（supply/enroll/select/verify） | `test_fate_consolidation.py` 七项回归全过，指纹审计 | 竞品无“分数+弃权+留痕”：我们交付的是**可进生产管线的判定**，不是一次生成 |
| 长上下文圣经（图边/冲突/有效期/问法覆盖学习） | 20k–100k 行抓取、留出问法 0→1.0 的学习曲线 | 竞品的人物资产是几张图；我们的是**带规则的故事级人物资产**，可迁移、可审计 |
| 机制负知识 | 补丁 0.978 塌缩、剂量曲线、原型通胀扣除（间隔仅 0.138）等全套证伪记录 | 知道每条路的死因与边界——这是调参型团队最缺的研发资产 |
| 模型无关框架与卸载调度 | discover/route/loader 实测巩固（卸载 193s→8.7s） | 可骑在任何本地/开源模型上演进，不陪葬于单一模型 |

### 2.2 现在还不是价值的东西（别高估）

- **规模证据不足**：无插件栈只测了 2 场景 × 3 种子；竞品都在宣传
  级素材上卷，我们没有同台对标（同提示词、同裁判跑 Runway/Vidu）。
- **视频闭环未合**：单 take 0.90 已证，但跨窗口“多条生成→选首帧”
  的视频版选择门还没端到端跑过；竞品卖的是成片。
- **指定外来真脸做不了**（实测 0.372 弃权）——这是竞品参考机制的
  主场，我们只能诚实弃权或接 ConsisID/Phantom 这类开源注入。
- **多主角同框未测**：身份间隔 0.138 是已知软肋，竞品（Vidu 7 主体）
  恰好主打这个。
- **无产品形态**：无 UI、无 API 服务、无多用户/计费；今天它是一项
  已验证的机制 + 框架代码，离收入还差一层产品化。

### 2.3 价值定位（一句话）

当前最准确的定位是 **“AI 影视一致性控制层（Consistency OS）”的
技术内核**：不生产像素，负责让别人的像素在长篇叙事里不漂、不串、
可量化验收。参照系：消费级生成订阅 $9–115/月、视频 API
$0.04–0.235/秒、企业数字人 $12k–60k/年——控制层适合按
“验收通过的分钟数/项目数”向制作方收费，而非按生成量和平台拼价。

## 3. 与竞品的逐项对位

| 维度 | 平台型竞品（Runway/Vidu/Flow） | 开源注入（ConsisID/Phantom/IP） | **我们（Fate 控制层）** |
|---|---|---|---|
| 一致性机制 | 参考图灌入自家模型 | 参考图注入开源模型 | 文本供给（逐字钉死）+ 候选选择 + 验证弃权 |
| 指定外来真脸 | 强（主场） | 强 | 弱（实测弃权，需外接注入模型） |
| 虚构角色长链 | 可用，靠人肉管参考图 | 可用 | **已测同档/略优，且资产结构化** |
| 多主体 | Vidu 7 主体领先 | Phantom 多主体 | 未测，间隔 0.138 是软肋 |
| 故事级上下文 | 无（提示词级） | 无 | **圣经：冲突/有效期/抓取/问法覆盖** |
| 质量判定与审计 | 无分数，肉眼验收 | 无 | **ArcFace 分数 + 指纹 + 弃权留痕** |
| 模型绑定 | 死绑自家 | 绑基座 | **模型无关，本地/API 皆可挂** |
| 成本形态 | 按秒/积分付费上云 | 本地算力 | 本地算力（出图约 2.5s/张，边际成本近电费） |
| 数据隐私 | 上云 | 本地 | 本地 |

## 4. 提升路线（按性价比排序）

### P0：把证据补到能卖（2–4 周量级，全部是已会做的事）

1. **无插件 12 场景长链**对表 IP 极限测验（同 0.5516/24 段门槛）——
   过了，`identity_no_plugin` 才从“简单测试”升级为“可宣称”。
2. **同台对标**：同提示词、同 ArcFace 裁判，至少跑 Vidu/Kling
   （API 可购）与本地 ConsisID/Phantom 各一条链，产出第一张
   “我们 vs 竞品”的可信数字表；同时采用 OpenS2V-Eval 口径，
   避免自说自话的指标。
3. **视频选择门端到端**：CogVideoX 多 take 生成→首帧对锚选择→
   拼接，把单 take 0.90 推到跨窗口，给短剧场景一个成片级演示。
4. **双角色分离**：双人同故事（发色/服装/锚各自独立）测串脸率；
   若间隔不够，引入“锚选择 + 服装/发型通道分数”的复合裁判。

### P1：产品化成控制层（价值变现的前提）

5. **FateInterface 服务化**：REST/SDK，把 select/verify 做成
   “任何生成器的外挂质检”——用户用 Kling/Runway 出 4 条，
   我们负责选与弃权。这一形态直接对着“减少抽卡损耗”的行业
   成本曲线收费（按验收分钟数计价），且不与平台抢生成。
6. **抽卡损耗计算器**：用我们的实测分布（池均 0.610、选择后
   最低 0.603、弃权率）给制作方算“每分钟合格素材省了几次重抽”，
   把机制翻译成钱——这是销售语言，不是技术语言。
7. **FLUX 供给上限测试**：FLUX 的 T5 通道能吃几百 token 身份描述，
   圣经供给在 FLUX 上的上限没测过；若成立，无插件路线的主力
   模型可以从 SDXL 换成画质更好的 FLux 系（它本来就没有 IP 通道，
   之前被排除在身份任务外，裁定可翻）。
8. **角色资产格式**：把圣经人物条目做成可导出的“角色包”
   （身份块+否定事实+锚图+有效期服装表），对标 Ideogram 保存角色、
   Vidu 主体库——但带规则，这是差异化所在。

### P2：补短板与防御

9. **指定真脸路由接开源注入**：ConsisID/Phantom 本地化接入
   `designated_external_face` 路由（框架已有其位），把唯一输给
   竞品的格变成“我们也能、且带验证门”。
10. **合规与溯源**：真人脸授权流程、生成溯源标记（对标 SynthID
    的企业要求）——企业客户（数字人那档 $12k+ 预算）会问这个。
11. **多模态一致性**：声音/口型一致性与合作方集成（HeyGen 式
    口播不是我们的菜，但短剧台词需要音色锚，可做同样的
    “锚+选择”复用）。

## 5. 风险提示

- **平台吸收风险（最大）**：Google 已把 Avatar 做进 Flow/Gemini，
  参考机制全员标配；若平台再补上“自动质检重抽”，控制层的独立
  价值会被压缩。防御只有两条：模型无关（不站队）和行业纵深
  （短剧制作流程里的圣经/冲突/有效期，平台短期不会做这么重）。
- **指标风险**：我们的 0.657 来自小样本且有原型通胀成分
  （真实间隔 0.138）；对外宣称前必须完成 P0 的同台对标，
  否则数字经不起竞品法务/技术尽调。
- **开源平替风险**：注入机制持续免费化，不要在那上面建收费点；
  收费点必须在判定、编排、资产格式与行业工作流上。

## 6. 总结裁定

- 现在的价值：**一套被实测（而非演示）证明的、无插件的人物一致性
  机制 + 可回归的控制层代码 + 一批稀缺的机制负知识**，踩中了
  AI 短剧从拼产能转向拼质量/降损耗的拐点。
- 与竞品的关系：不与平台拼生成（必输），做平台缺的质检与
  故事资产层（可合作、可被集成）。
- 下一步只做四件事：长链对表、同台对标、视频闭环、双角色——
  做完这四件，价值叙事从“机制成立”升级为“同台不输且更可控”，
  才谈得上定价。
